Simple exam notes based mainly on the faculty class notebook. Focus on understanding the code, why it is used, and what to write in the exam.

1

Big Picture

Linear Regression is used to predict a numeric value using one or more input variables.

Class example: Predict Premium of a vehicle using Mileage.
Premium = b0 + b1 × Mileage

Think of it as drawing the best straight line through the data points.

TermSimple meaning
XInput / predictor → Mileage
YOutput / target → Premium
b0Intercept
b1Slope

3

Ordinary Least Squares (OLS)

OLS finds the straight line that gives the smallest total squared error.

Minimise: Σ(y − ŷ)²

Here y is the actual value and ŷ is the predicted value.

Imagine several points on paper. OLS moves the line until the total squared distance between the points and the line is as small as possible.
4

Calculate b0 and b1 Manually

The faculty notebook calculates the slope and intercept directly.

x = df['Mileage']
y = df['Premium']

x_bar = np.mean(x)
y_bar = np.mean(y)

num = np.sum((x - x_bar) * (y - y_bar))
denom = np.sum((x - x_bar)**2)

b1 = num / denom
b0 = y_bar - b1 * x_bar

Formulas

b1 = Σ[(x − x̄)(y − ȳ)] / Σ[(x − x̄)²]
b0 = ȳ − b1x̄
SymbolMeaning
x̄Mean of X
ȳMean of Y
b1Slope
b0Intercept
Exam memory: Calculate b1 first, then use b1 to calculate b0.

Step-by-step:

  1. Calculate predicted Y using the equation.
  2. Plot the original X and Y points.
  3. Plot the predicted values as the regression line.
The line represents the predicted Premium for different Mileage values.
6

Build OLS Using Statsmodels

import statsmodels.api as sm

x = df['Mileage']
y = df['Premium']

xc = sm.add_constant(x)

mod = sm.OLS(y, xc)
ols_mod = mod.fit()

ols_mod.summary()
ols_mod.params

Why add_constant()?

It adds the constant/intercept column needed by statsmodels.OLS.

Important: ols_mod.params gives the estimated b0 and b1.
7

Interpret the Regression Equation

Premium = b0 + b1 × Mileage

Intercept (b0): predicted Premium when Mileage = 0.

Slope (b1): change in predicted Premium when Mileage increases by 1 unit.

Direction: Positive b1 → Premium increases as Mileage increases. Negative b1 → Premium decreases as Mileage increases.

Simple numerical example

Given: b0 = 100, b1 = −5, Mileage = 10

Formula: Premium = b0 + b1 × Mileage

Substitution: Premium = 100 + (−5 × 10)

Calculation: Premium = 100 − 50 = 50

Interpretation: For Mileage = 10, predicted Premium is 50.

Exam-Ready Answer: Simple Linear Regression

Definition: Simple Linear Regression predicts a numeric dependent variable using one independent variable.

Model: y = b0 + b1x

Steps:

  1. Load and understand the data.
  2. Choose X and Y.
  3. Check the relationship using a scatter plot and correlation.
  4. Use OLS to find the best-fit line.
  5. Calculate b1 and b0.
  6. Use the equation to predict Y.
  7. Build the model using statsmodels.OLS().
  8. Interpret b0 and b1.

Conclusion: Linear regression finds the best straight-line relationship between the predictor and target and uses it for prediction.
