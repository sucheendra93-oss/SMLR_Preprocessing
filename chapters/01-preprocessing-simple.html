Data Preprocessing — Simple Exam Kit

Simple exam notes based mainly on the faculty class notebook. Focus on understanding the code, why it is used, and what to write in the exam.

1

Data Summary

Purpose: First understand the dataset before changing anything.

df_sales.info()
df_sales.describe()
df_sales.describe(include="object")

for col in df_sales.select_dtypes(include='object'):
    print(df_sales[col].value_counts())
Remember: info() → columns, data types, non-null values. describe() → numeric summary. describe(include="object") → categorical summary.
2

Missing Values

Purpose: Find missing values and decide how to treat them.

df_sales.isnull().sum()

2.1 Drop rows

df_sales_drop = df_sales.dropna()

Use when only a small number of rows are missing and removing them will not hurt the dataset.

2.2 Categorical → Mode

df_sales.Outlet_Size.mode()
df_sales.Outlet_Size = df_sales.Outlet_Size.replace(np.nan, "Medium")

Mode = most common value. Use for categorical data.

2.3 Non-standard missing values

df_sales = df_sales.replace(["?", "--", "na", "NA", "NAN"], np.nan)
df_sales.isnull().sum()
Exam point: Convert values such as NA, ?, -- to np.nan first. Then treat them.

2.4 Numeric → Mean or Median

# roughly symmetric data
df_sales["Item_Weight"] = df_sales["Item_Weight"].fillna(
    df_sales["Item_Weight"].mean())

# skewed data
med = df_sales["Item_Visibility"].median()
df_sales.Item_Visibility = df_sales.Item_Visibility.replace(0, med)
Easy rule: Mean → roughly symmetric. Median → skewed / outliers. Mode → categorical.

2.5 Domain knowledge

Sometimes a missing value can be filled using another related column and a business rule. The class notebook uses sales to decide the outlet location tier.

3

Encoding Categorical Data

ML algorithms need numbers, so categorical values must be converted into numbers.

3.1 One-Hot Encoding — Pandas

dummy_encode1 = pd.get_dummies(
    df_sales, columns=['Item_Type'], dtype=np.uint)

dummy_encode2 = pd.get_dummies(
    df_sales, drop_first=True, columns=['Item_Type'])

Use: categories with no natural order. Each category becomes a 0/1 column.

drop_first=True: if there are k categories, keep k−1 dummy columns. Useful for linear regression.

3.2 One-Hot Encoding — sklearn

from sklearn.preprocessing import OneHotEncoder

encode1 = OneHotEncoder()

df_encode1 = pd.DataFrame(
    encode1.fit_transform(df_sales[['Outlet_Type']]).toarray()
)

The class also shows the cleaner form:

encode2 = OneHotEncoder(
    sparse_output=False, drop="first"
).set_output(transform="pandas")

3.3 Label Encoding

from sklearn.preprocessing import LabelEncoder

labelencoder = LabelEncoder()
df_sales['Label_Encoded_Outlet_Size'] = \
    labelencoder.fit_transform(df_sales.Outlet_Size)

It changes categories to integer labels. The class example uses it on Outlet_Size.

3.4 Ordinal Encoding

from sklearn.preprocessing import OrdinalEncoder

orderencoding = OrdinalEncoder(
    categories=[["Small", "Medium", "High"]])

df_sales['Order_Outlet_Size'] = \
    orderencoding.fit_transform(df_sales[['Outlet_Size']])
Easy difference: Label Encoding → gives labels. Ordinal Encoding → you explicitly give the correct order.

3.5 Frequency Encoding

encoding = df_sales.groupby('Item_Type').size()
encoding = encoding / len(df_sales)

df_sales['Freq_Encoded_Item_Type'] = \
    df_sales.Item_Type.map(encoding) * 100

Each category is replaced by how frequently it appears.

3.6 Target / Mean Encoding

mean_encoded = df1.groupby('smoker')['target'].mean()
df1['encoded_smoker'] = df1['smoker'].map(mean_encoded)

Each category is replaced by the average target value for that category.

4

Scaling

Purpose: Put numeric variables on comparable scales so a large-valued feature does not dominate just because of its size.

4.1 StandardScaler

from sklearn.preprocessing import StandardScaler

standard_scale = StandardScaler()

df_sales['Scaled_Item_Outlet_Sales'] = \
    standard_scale.fit_transform(
        df_sales[['Item_Outlet_Sales']])
z = (x − mean) / standard deviation

Result: mean is approximately 0 and standard deviation approximately 1.

4.2 Min-Max Normalization

from sklearn.preprocessing import MinMaxScaler

min_max = MinMaxScaler()

df_sales['minmax_Item_Outlet_Sales'] = \
    min_max.fit_transform(df_sales[['Item_Outlet_Sales']])
x' = (x − min) / (max − min)

Result is between 0 and 1.

Remember: StandardScaler → mean 0, std 1. Min-Max → range 0 to 1.
5

Transformation

Transformation changes the shape of data. The class notebook studies Log and Exponential transformation.

5.1 Log Transformation

print(df_sales['Item_Outlet_Sales'].skew())

np.log(df_sales['Item_Outlet_Sales']).skew()

sns.histplot(np.log(df_sales['Item_Outlet_Sales']), kde=True)

Log transformation is useful for reducing right skew.

log(x) → reduces a long right tail

5.2 Exponential Transformation

np.exp(np.log(df_sales['Item_Outlet_Sales']))

Exponential reverses the log transformation.

Remember: np.log(x) cannot be used directly when x is 0 or negative.
6

Outliers

Outlier: a value that is unusually far from the other observations. Outliers can affect results.

6.1 Boxplot

df_num = df_sales.select_dtypes(include=np.number)
df_num.boxplot()

Boxplots give a visual way to spot unusual values.

6.2 IQR Method

Q1 = df_num.quantile(0.25)
Q3 = df_num.quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
IQR = Q3 − Q1
Lower = Q1 − 1.5(IQR)
Upper = Q3 + 1.5(IQR)

Values below lower or above upper are treated as outliers.

6.3 Z-Score

from scipy import stats

z_scores = scipy.stats.zscore(df_num["Profit"])

# outliers
z_scores < -3
z_scores > 3
z = (x − mean) / standard deviation

If z > 3 or z < −3, the class notebook considers it an outlier.

6.4 Scatter Plot

sns.scatterplot(
    x=df_sales["Profit"],
    y=df_sales["Item_Outlet_Sales"])

Scatter plots show relationships between two numeric variables and can also help identify unusual points.

7

Feature Engineering

Feature engineering means creating a useful new feature from existing data.

Example 1 — Outlet Age

from datetime import date

current_year = date.today().year

df_sales["Age_Outlet"] = \
    current_year - df_sales["Outlet_Establishment_Year"]

Instead of using only the establishment year, we create the outlet's age.

Example 2 — Product Type

df_sales['Product_type'] = \
    df_sales['Item_Identifier'].apply(lambda x: x[0:2])

df_sales['Product_type'] = df_sales['Product_type'].map({
    'FD':'Food',
    'NC':'Non-Consumable',
    'DR':'Drinks'
})

The first two characters of Item_Identifier are converted into a meaningful product type.

Train and Test Split

Split the data so the model learns from one part and is tested on unseen data.

from sklearn.model_selection import train_test_split

Y = df_sales['Item_Outlet_Sales']
X = df_sales.drop(['Item_Outlet_Sales'], axis=1)

X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.25, random_state=100)
Meaning: X = input/features. Y = target. test_size=0.25 means 25% test data and 75% training data. random_state=100 makes the split reproducible.

Exam-Ready Answer: Data Preprocessing

Definition: Data preprocessing is the process of preparing raw data for machine learning.

Steps:

  1. Understand the data using info() and describe().
  2. Detect and treat missing values.
  3. Convert categorical data into numeric form using suitable encoding.
  4. Scale numeric features when required.
  5. Transform skewed data if needed.
  6. Detect outliers using boxplot, IQR, Z-score or scatter plot.
  7. Create useful features through feature engineering.
  8. Split data into training and testing sets.

Conclusion: Proper preprocessing improves the quality and suitability of data for machine learning.
