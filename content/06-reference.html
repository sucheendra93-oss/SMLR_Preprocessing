sklearn.preprocessing encoders & scalers

ClassSummaryExample
OneHotEncoder()Makes one 0/1 column per category. Returns a sparse matrix by default → .toarray() or sparse_output=False. Use when you need to persist/reuse the fitted encoding.
enc = OneHotEncoder(sparse_output=False, drop="first")
df_enc = enc.fit_transform(df[["Outlet_Type"]])
LabelEncoder()Assigns integers alphabetically to categories — arbitrary order. Safe only for the target variable or genuinely ordinal features.df["y_enc"] = LabelEncoder().fit_transform(df["Outlet_Size"])
OrdinalEncoder(categories=[[...]])You supply the true category order, so the resulting integers carry meaning (Small<Medium<High).OrdinalEncoder(categories=[["Small","Medium","High"]]).fit_transform(df[["Outlet_Size"]])
StandardScaler()z-score scaling: (x−mean)/std → mean 0, std 1, unbounded. Keeps outlier impact. Needed before Ridge/Lasso.
scaler = StandardScaler()
X_train[cols] = scaler.fit_transform(X_train[cols])
X_test[cols]  = scaler.transform(X_test[cols])
MinMaxScaler()Normalisation: (x−min)/(max−min) → fixed [0,1] range. Very sensitive to outliers.df["mm_sales"] = MinMaxScaler().fit_transform(df[["Item_Outlet_Sales"]])
!Shared method patternEvery encoder/scaler: .fit_transform(X_train) to fit + apply on train, then .transform(X_test) — never re-fit — on test. Fitting on the full dataset before splitting is data leakage.

sklearn.linear_model regression models

ClassSummaryExample
LinearRegression()Plain OLS regression. Adds its own intercept automatically — never call add_constant with it.model = LinearRegression().fit(X_train, y_train); model.predict(X_test)
SGDRegressor()Linear regression fit by (stochastic) gradient descent instead of the closed-form OLS solution — used for very large data; has mild built-in regularization.sgd = SGDRegressor(random_state=0).fit(X_train, y_train)
Ridge(alpha)L2-regularized regression — penalty Σβ². Shrinks all coefficients towards 0 but never exactly to 0.ridge = Ridge(alpha=1).fit(X_train, y_train)
Lasso(alpha)L1-regularized regression — penalty Σ|β|. Can drive weak coefficients to exactly 0 → built-in feature selection.lasso = Lasso(alpha=0.5).fit(X_train, y_train)
ElasticNet(alpha, l1_ratio)Combines L1+L2. l1_ratio=0 → pure Ridge, =1 → pure Lasso, between → a blend.enet = ElasticNet(alpha=0.1, l1_ratio=0.01).fit(X_train, y_train)
iShared method patternAll five: .fit(X_train, y_train), .predict(X_test), .score(X, y) (returns R²), .coef_ (slopes), .intercept_ (b0). alpha is the regularization strength (hyperparameter) for Ridge/Lasso/ElasticNet — 0 = plain OLS, bigger = more shrinkage.

Feature selection RFE · SequentialFeatureSelector

ClassSummaryExample
RFE(estimator, n_features_to_select)Recursive Feature Elimination — fits the model, ranks features by importance, drops the weakest, repeats. .ranking_ gives each feature's rank (1 = keep); an instance of backward elimination.
rfe = RFE(LinearRegression(), n_features_to_select=5).fit(X_train, y_train)
X_train.columns[rfe.support_]
sfs(estimator, k_features, forward, scoring)mlxtend's SequentialFeatureSelector. forward=True = forward selection (start empty, add best feature each step); forward=False = backward elimination (start full, drop weakest). k_features: an int, a range (lo,hi), or 'best'.
sfs_fwd = sfs(LinearRegression(), k_features=6, forward=True, scoring="r2")
sfs_fwd = sfs_fwd.fit(X_train, y_train)
sfs_fwd.k_feature_names_
iKey attributesAfter .fit(): sfs gives .k_feature_names_ and .k_score_; RFE gives .ranking_ and .support_ (boolean mask of selected columns).

statsmodels import statsmodels.api as sm

CallSummaryExample
sm.add_constant(X)Adds a column of 1s so OLS can estimate the intercept b0. Required for statsmodels — it does NOT add one for you (unlike sklearn's LinearRegression).Xc = sm.add_constant(X_train)
sm.OLS(y, X).fit()Fits ordinary least squares; returns a results object with everything below.model = sm.OLS(y_train, Xc).fit()
model.summary()The full stats report: coefficients, std errors, t-stats, p-values, R², Adj R², F-statistic, Durbin-Watson, Jarque-Bera.print(model.summary())
model.paramsFitted coefficients (β₀, β₁, …) as a Series.model.params # const 327.086, Mileage -11.6905
model.pvaluesp-value per coefficient — >0.05 means that feature is statistically insignificant (a backward-elimination drop candidate).model.pvalues.sort_values(ascending=False)
model.rsquared / model.rsquared_adjR² and Adjusted R² of the fitted model.model.rsquared, model.rsquared_adj
model.fvalue / model.f_pvalueThe F-statistic and its p-value — tests whether the whole model (not just one coefficient) is significant.model.fvalue, model.f_pvalue
model.residResiduals (actual − predicted) for every training row — feeds every assumption check.sns.histplot(model.resid, kde=True)
model.fittedvaluesThe model's predicted values on the data it was fit on.y_pred = model.fittedvalues
qqplot(resid, line='s')Q-Q plot of residuals — points on the 45° line ⇒ residuals are normally distributed.qqplot(model.resid, line="s")
sms.het_breuschpagan(resid, X)Breusch-Pagan test for homoscedasticity. H₀ = constant variance; p > 0.05 → homoscedastic (good).bp = sms.het_breuschpagan(model.resid, X_train)
het_goldfeldquandt(resid, X)Alternative homoscedasticity test — same H₀/decision rule as Breusch-Pagan.stat, p_value, _ = het_goldfeldquandt(model.resid, X_train)
variance_inflation_factor(X.values, i)VIF for column i — 1/(1−R²) of that feature regressed on the rest. VIF>5 ⇒ high multicollinearity, drop it.[variance_inflation_factor(X.values, i) for i in range(X.shape[1])]
!The one everyone forgetssm.OLS does not add an intercept — skip sm.add_constant(X) and you silently fit a line forced through the origin.

✓Full worked example
def objective(trial):
    params = {"alpha": trial.suggest_float("alpha", 0.0001, 10)}
    ridge = Ridge(**params).fit(X_train, y_train)
    return get_test_rmse(ridge)          # lower RMSE = better

study = optuna.create_study(direction="minimize", sampler=TPESampler(seed=10))
study.optimize(objective, n_trials=100)
ridge_best = Ridge(**study.best_trial.params).fit(X_train, y_train)
