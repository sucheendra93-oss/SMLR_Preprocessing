sklearn.preprocessing encoders & scalers

ClassSummary
OneHotEncoder()Makes one 0/1 column per category. Returns a sparse matrix by default → .toarray() or sparse_output=False. Use when you need to persist/reuse the fitted encoding.
LabelEncoder()Assigns integers alphabetically to categories — arbitrary order. Safe only for the target variable or genuinely ordinal features.
OrdinalEncoder(categories=[[...]])You supply the true category order, so the resulting integers carry meaning (Small<Medium<High).
StandardScaler()z-score scaling: (x−mean)/std → mean 0, std 1, unbounded. Keeps outlier impact. Needed before Ridge/Lasso.
MinMaxScaler()Normalisation: (x−min)/(max−min) → fixed [0,1] range. Very sensitive to outliers.
!Shared method patternEvery encoder/scaler: .fit_transform(X_train) to fit + apply on train, then .transform(X_test) — never re-fit — on test. Fitting on the full dataset before splitting is data leakage.

sklearn.model_selection splitting, CV, tuning

Class / functionSummary
train_test_split(X, y, test_size, random_state)Splits into train/test sets; random_state fixes the shuffle for reproducibility.
cross_val_score(estimator, X, y, cv, scoring)Runs k-fold CV, returns one score per fold (e.g. R²) — average for an honest, less-lucky performance estimate.
LeaveOneOut()CV splitter where k = n rows — each fold tests on exactly one row. Thorough but slow; only for small data.
GridSearchCV(estimator, param_grid, cv)Exhaustively tries every hyperparameter combination with CV; .best_params_ / .best_estimator_ give the winner. Thorough but slow on big grids.
RandomizedSearchCV(estimator, param_distributions, cv, n_iter)Tries n_iter random hyperparameter combinations instead of all — faster, usually lands close to optimal.

sklearn.linear_model regression models

ClassSummary
LinearRegression()Plain OLS regression. Adds its own intercept automatically — never call add_constant with it.
SGDRegressor()Linear regression fit by (stochastic) gradient descent instead of the closed-form OLS solution — used for very large data; has mild built-in regularization.
Ridge(alpha)L2-regularized regression — penalty Σβ². Shrinks all coefficients towards 0 but never exactly to 0.
Lasso(alpha)L1-regularized regression — penalty Σ|β|. Can drive weak coefficients to exactly 0 → built-in feature selection.
ElasticNet(alpha, l1_ratio)Combines L1+L2. l1_ratio=0 → pure Ridge, =1 → pure Lasso, between → a blend.
iShared method patternAll five: .fit(X_train, y_train), .predict(X_test), .score(X, y) (returns R²), .coef_ (slopes), .intercept_ (b0). alpha is the regularization strength (hyperparameter) for Ridge/Lasso/ElasticNet — 0 = plain OLS, bigger = more shrinkage.

Feature selection RFE · SequentialFeatureSelector

ClassSummary
RFE(estimator, n_features_to_select)Recursive Feature Elimination — fits the model, ranks features by importance, drops the weakest, repeats. .ranking_ gives each feature's rank (1 = keep); an instance of backward elimination.
sfs(estimator, k_features, forward, scoring)mlxtend's SequentialFeatureSelector. forward=True = forward selection (start empty, add best feature each step); forward=False = backward elimination (start full, drop weakest). k_features: an int, a range (lo,hi), or 'best'.
iKey attributesAfter .fit(): sfs gives .k_feature_names_ and .k_score_; RFE gives .ranking_ and .support_ (boolean mask of selected columns).

sklearn.metrics error & fit metrics

FunctionSummary
mean_absolute_error(y_true, y_pred)MAE — average of |errors|, same units as target, robust to outliers.
mean_squared_error(y_true, y_pred)MSE — average of squared errors; take np.sqrt() for RMSE, which punishes big misses more.
mean_absolute_percentage_error(y_true, y_pred)MAPE — average error as a fraction of the true value; ×100 to read as a percentage.
r2_score(y_true, y_pred)R² computed from explicit predictions (vs. model.score() which does the same thing on a fitted estimator).

statsmodels import statsmodels.api as sm

CallSummary
sm.add_constant(X)Adds a column of 1s so OLS can estimate the intercept b0. Required for statsmodels — it does NOT add one for you (unlike sklearn's LinearRegression).
sm.OLS(y, X).fit()Fits ordinary least squares; returns a results object with everything below.
model.summary()The full stats report: coefficients, std errors, t-stats, p-values, R², Adj R², F-statistic, Durbin-Watson, Jarque-Bera.
model.paramsFitted coefficients (β₀, β₁, …) as a Series.
model.pvaluesp-value per coefficient — >0.05 means that feature is statistically insignificant (a backward-elimination drop candidate).
model.rsquared / model.rsquared_adjR² and Adjusted R² of the fitted model.
model.fvalue / model.f_pvalueThe F-statistic and its p-value — tests whether the whole model (not just one coefficient) is significant.
model.residResiduals (actual − predicted) for every training row — feeds every assumption check.
model.fittedvaluesThe model's predicted values on the data it was fit on.
qqplot(resid, line='s')Q-Q plot of residuals — points on the 45° line ⇒ residuals are normally distributed.
sms.het_breuschpagan(resid, X)Breusch-Pagan test for homoscedasticity. H₀ = constant variance; p > 0.05 → homoscedastic (good).
het_goldfeldquandt(resid, X)Alternative homoscedasticity test — same H₀/decision rule as Breusch-Pagan.
variance_inflation_factor(X.values, i)VIF for column i — 1/(1−R²) of that feature regressed on the rest. VIF>5 ⇒ high multicollinearity, drop it.
!The one everyone forgetssm.OLS does not add an intercept — skip sm.add_constant(X) and you silently fit a line forced through the origin.

optuna Bayesian hyperparameter search

CallSummary
optuna.create_study(direction, sampler)Starts a tuning study; direction='minimize' for an error metric like RMSE. TPESampler(seed=...) makes it reproducible.
study.optimize(objective, n_trials)Runs the search: each trial calls your objective(trial) function, which builds a model and returns the score to minimise/maximise.
trial.suggest_float(name, low, high)Inside objective — asks Optuna to propose a value for one hyperparameter in a given range.
study.best_trial.value / .paramsThe best score found and the hyperparameters that produced it.
✓vs. Grid/Randomized searchOptuna is Bayesian — each trial learns from the previous ones and steers toward promising regions, so it needs far fewer trials than an exhaustive grid.
